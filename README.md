# Qadam Delivery

Платформа городской доставки для частных клиентов и небольших магазинов Алматы.
Клиент оформляет отправление в Telegram, курьер принимает заказ и обновляет его
статус, а клиент следит за доставкой в том же Mini App.

[Открыть в Telegram](https://t.me/qadam_delivery_bot) ·
[Веб-страница](https://qadam-delivery.vercel.app)

## Возможности

- **Клиентам:** создание заказа с адресами и получателем, выбор желаемого времени,
  история доставок и повтор заказа.
- **Магазинам:** необязательный профиль с сохранённым адресом и указаниями входа.
  Личные и магазинные отправления доступны в одном интерфейсе.
- **Курьерам:** подача заявки, режим «Я на линии», доступные заказы, принятие
  доставки со свежей геопозицией и последовательное изменение статусов.
  Можно закончить смену после текущих доставок.
- **Карта:** поиск адресов, автомобильный маршрут и последняя позиция курьера.
  Свободные курьеры на линии показываются с приблизительными координатами,
  в том числе при заполнении получателя и проверке заказа.
- **Геолокация курьера:** после согласия передача включается автоматически
  в открытом Qadam. Для новых заказов нужны действующая смена и свежая позиция.
  Подготовлена закрытая проверка трансляции Telegram во время внешней навигации;
  она запускается отдельно в чате. Автоматический фон без участия курьера
  потребует отдельного мобильного приложения.
- **Уведомления:** сообщения Telegram о заявках курьеров, новых заказах и ходе доставки.
- **Администраторам:** рассмотрение заявок, список и общее число курьеров,
  поиск заказов, назначение и смена курьера, отмена с причиной и ограничение
  курьерского доступа. Решения сохраняются в истории.
- **Вручение:** после подключения сервиса — приватное фото упаковки и код по
  желанию отправителя. После доставки можно оставить оценку для команды Qadam.
- **Приватность:** контакты участников и текст открытки доступны назначенному
  курьеру после принятия заказа; доступ к данным проверяется на сервере.

## Как проходит доставка

1. Клиент указывает, откуда забрать и куда доставить посылку, заполняет данные
   получателя и проверяет заказ.
2. Курьер выходит на линию, передаёт свежую позицию, принимает заказ и получает
   контакты для связи.
3. Курьер отмечает получение посылки, начало пути и завершение доставки.
4. Клиент видит изменения статуса, последнюю геопозицию и сохранённую историю.

## Технологии

| Часть | Технологии |
| --- | --- |
| Интерфейс | Next.js 16, React 19, TypeScript, Tailwind CSS |
| Собственный API | Node.js, Next.js Route Handlers, Zod |
| База данных | PostgreSQL, `pg`, SQL-миграции |
| Карты | Leaflet, Geoapify, OpenStreetMap |
| Telegram | Mini Apps SDK, Bot API |
| Проверки | Node.js Test Runner, Playwright, GitHub Actions |
| Размещение и локальная среда | Vercel, Supabase PostgreSQL, Docker Compose |

Серверная логика находится в репозитории: авторизация, права доступа, работа с
заказами и уведомлениями реализованы в собственном API. Также подготовлен вариант
с отдельными интерфейсом, API и PostgreSQL в Docker.

## Локальная разработка

Требования: Node.js 22.14+, npm и запущенный Docker с Docker Compose.

1. Установите зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env`. Задайте собственные локальные
   `POSTGRES_PASSWORD` и `DEMO_PASSWORD`. Пароль PostgreSQL должен совпадать
   в `POSTGRES_PASSWORD`, `DATABASE_URL` и `TEST_DATABASE_URL`.
3. Запустите базу, примените миграции и подготовьте локальные аккаунты:

   ```sh
   docker compose up -d --wait
   npm run db:migrate
   npm run db:seed
   npm run dev
   ```

Приложение будет доступно по адресу [localhost:3000](http://127.0.0.1:3000).
Локальный браузерный вход используется для разработки; публичный Mini App
открывается через Telegram.

Для запуска всех трёх сервисов в контейнерах см.
[инструкцию Docker и отдельного API](docs/BACKEND_API.md).

## Проверки

При работающей локальной PostgreSQL и настроенном `.env`:

```sh
npm run db:test:setup
npm run typecheck
npm test
npm run build
npm run check:build
npm run test:e2e
```

Интеграционные тесты используют отдельную базу с именем, заканчивающимся на `_test`.
Для локальных браузерных тестов нужен Google Chrome; в GitHub Actions используется
Chromium. Проверяется полный путь заказа, доступ к данным и работа отдельного API.

## Текущие ограничения

- Автоматический расчёт стоимости пока выключен. Стоимость согласуется,
  оплата производится напрямую курьеру.
- Геопозиция обновляется при активном Mini App и разрешении пользователя.
  Фонового отслеживания при закрытом приложении нет; устаревшие точки отмечаются.
- Трансляция из чата Telegram подключается отдельно для активного заказа;
  её работа с навигатором на телефоне проверяется перед общим включением.
  Подробнее — [этап 7.1](docs/STAGE_7_1.md).
- Желаемый интервал доставки не означает автоматического резервирования курьера.
- Фото и код включаются серверной настройкой; требования сохраняются на момент
  создания заказа. Фото доступно в приложении до 30 суток. Настройка и проверка —
  в [инструкции этапа 7](docs/STAGE_7.md).
