## Проверенная цепочка

Настоящий Chrome, итоговая сборка и локальная PostgreSQL `_test`. Telegram SDK
получает синтетическую подпись. Обновление Telegram отправлено на настоящий
защищённый webhook приложения с синтетическим секретом, а не прямо в функцию БД.
Реальные внешние сообщения и координаты пользователей для автоматических тестов
не использовались; тайлы карты заменены локальной фикстурой.

Курьер сохраняет согласие, выключает и включает линию без повторного согласования,
принимает заказ и подключает трансляцию. Защищённый webhook связывает новое
сообщение и обновляет точку клиента. Страница курьера закрывается; следующий
webhook продолжает обновлять заказ клиента. Проверены отметка устаревания,
остановка и отзыв через интерфейс, сохранённое состояние на сервере.

На сервере проверены запрещённые отправители и пересылки, разовые точки,
просроченные/повторные сообщения, ограничения пилота, чужой заказ, старая версия
назначения, закрытие при смене/блокировке/завершении/выключении линии. Ранее
использованное сообщение не привязывается заново после немедленного повтора.
Mini App GPS не перезаписывает Telegram во время выбранной сессии. Трансляция
не раскрывает точные координаты на общей карте. Очередь бота не сохраняет GPS.

## Интерфейс и инфраструктура

Макет проверен на 320/390/1280 px и визуально просмотрен. Скриншоты работающего
мобильного интерфейса подключения, активной сессии и карты клиента просмотрены;
сохраняются стили Qadam и доступные поля согласия. Артефакты — в игнорируемых
`artifacts/stage-7-1/` и `test-results/`.

Три миграции применены в Supabase, SHA-256 совпадают с журналом. Новая таблица
имеет RLS; anon/authenticated/service_role не имеют SELECT. qadam_app имеет
необходимые SELECT/INSERT/UPDATE. Триггеры не используют SECURITY DEFINER.
Проверка рабочего transaction pooler выявила недостающий UPDATE для новой колонки
location_source; исправление сохранено отдельной миграцией и повторно проверено.
TLS 1.3 подтверждён, автотариф выключен. Security advisor не выявил новых замечаний;
сохраняется прежняя информационная запись о закрытом журнале миграций
([описание](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy)).

В Vercel параметры созданы только для Production. Список согласованных аккаунтов
хранится как sensitive; реальный Telegram ID не включён в код и документы.
Курьерский доступ согласованного аккаунта проверен без изменения его роли.
