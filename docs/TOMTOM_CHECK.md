## Существенные ограничения

1. **Версии расходятся.** Например, Атакент → Dostyk Plaza: Orbis live 11.05 км / 24.6 мин, v1 7.53 км / 19.4 мин. Сайран → Арбат: Orbis 15.08 км, v1 8.59 км. Успешный HTTP-ответ не доказывает качество цены. Нужна сверка допустимых дорог, актуальных перекрытий и реальных поездок; выбрать правильную версию только по этой таблице нельзя.
2. **Время.** Orbis v3 в этом прогоне возвращает смещение `+06:00`, а v1 — `+05:00`. После учёта смещения абсолютное время соответствует моменту запроса. Для Qadam сохранять UTC и форматировать через `Asia/Almaty`, не копировать отображаемые часы поставщика. Влияние часового пояса поставщика на исторические прогнозы отдельно не доказано. Официальная информация о [переходе Казахстана на UTC+5](https://www.gov.kz/org/mti/press/news/details/688998?lang=ru).
3. **Транспорт.** Документация Orbis v3 указывает `car` и `taxi`; пеший/мопедный профиль этой версии не подтверждён. Контроль v1 для Зелёного базара → Dostyk Plaza вернул пеший маршрут 3.78 км / 45.4 мин и motorcycle 4.26 км / 12.4 мин. Motorcycle обозначен в документации как beta с неполными ограничениями в отдельных местах. Это не доказывает пригодность для каждого мопеда/электромопеда.
4. **Поиск объектов.** Предварительный TomTom POI Search по некоторым названиям возвращал неподходящие объекты (в частности, запрос Dostyk Plaza дал объект на Абая). Он не выбирался автоматически как конечная точка. Эти результаты не переносятся на новый Places Search API, который отдельно не проверялся. Существующий Geoapify/подтверждение точки сохраняем.
5. **Нулевой delay.** Такой ответ сам по себе не доказывает пустую дорогу или полное покрытие трафиком. Нельзя обещать точное время вручения; оно включает ещё поиск, подачу и передачу.
6. **Условия данных.** [Обзор Orbis v3](https://docs.tomtom.com/routing-api/documentation/tomtom-orbis-maps/v3/product-information/introduction) описывает показ маршрутов на картах других поставщиков. Полный текст условий аккаунта, атрибуцию и сроки хранения производных данных ещё нужно проверить до Production.

## Как воспроизвести

Ключ владелец хранит только в игнорируемом `.env.local` как `TOMTOM_API_KEY`. Значение не передаётся аргументом командной строки. Не публиковать его в чате, Git или скриншотах.

```powershell
# Только проверка публичных входных точек, без ключей и сети
node scripts/check-tomtom.mjs --offline

# Один ограниченный сетевой прогон
npm run check:tomtom
```

Команда останавливается при HTTP 401/403/429, ограничивает время/размер ответа и сохраняет только выбранные числовые поля. Сырые тела ошибок, URL с ключом и полная геометрия в отчёт не попадают. Отчёт записывается в игнорируемый `artifacts/tomtom-check.json`; старый результат заменяется. Повторный запуск расходует новую квоту.
Тела `.env` не выводились и не открывались для просмотра; Node загрузил настройки внутри процесса. Ключ Orbis передаётся заголовком, контрольный v1 — документированным query-параметром только внутри процесса. Скрипт не входит в сборку приложения и не запускается в CI автоматически.

## Следующие действия

- Не утверждать конкретные денежные ставки или Production-поставщика на основании одного технического прогона.
- Сверить несколько спорных маршрутов с допустимым движением и фактическими поездками. Первый сбор [девяти предложений рынка](pricing-observations.md) завершён, привязка маршрутов подтверждена владельцем; транспорт и остальные условия ещё не полностью сопоставимы.
- Выбрать транспортные классы пилота и проверить их расходы/оплату времени. Для пешего курьера считать пеший маршрут; автомобильные пробки не переносить в пешую цену.
- После проверки качества и условий утвердить источник, коэффициенты и макет. Затем реализовывать [план этапа 5](STAGE_5_PLAN.md).
