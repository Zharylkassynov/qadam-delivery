# Краткие клиентские экраны заказа

16 ноября 2026. Доработка этапа 9 по прямому запросу владельца:
убрать «Путь заказа» и лишние тексты при поиске курьера и после доставки.
Используются существующие экраны, компоненты и оформление Onest/Qadam;
новый этап и новая визуальная концепция не вводятся.

- Клиент больше не видит ленту «Путь заказа», включая раскрытие активного заказа.
  События сохраняются на сервере и доступны в существующих курьерских и
  административных представлениях.
- При поиске один заголовок статуса; повторное уведомление «Заказ создан» скрыто.
  На виду карта, адреса, стоимость, плательщик, способ оплаты, срок и важные отметки.
  Получатель, комментарий и полные условия — в «Детали заказа».
- После доставки на виду результат, дата, адреса, стоимость, фото при наличии,
  оценка и повтор заказа. Карта, подробности и управление ссылкой свёрнуты.
  Отключение ссылки остаётся доступным после завершения.
- Поле комментария к оценке появляется после выбора звёзд. Ошибки, сроки доступа
  к фото и предупреждение о доступе по ссылке сохранены. Сумма не помечается
  оплаченной: приложение не проверяет передачу денег.

Новых миграций, настроек и изменений API нет. Основная проверка — реальный
локальный браузер → API → отдельная `_test` БД: поиск, переход до вручения,
оценка, повторное открытие и сохранность событий. Также проверяются обе темы,
320/390/768/1280, фото, ссылка получателю и существующие роли.

Проверки: typecheck, 201 серверная проверка, build и check:build (46 + 46 API)
прошли. Пройдены все 59 браузерных сценариев: 53 совмещённого приложения,
5 самостоятельного API и 1 защищённой передачи через отдельный API.
В одном существующем сценарии ожидание убранной фразы «Заказ создан» заменено
проверкой заголовка «Ищем курьера»; повтор подтвердил сохранение одного заказа
при потере ответа сервера.

После корректировки размеров карты и блока стоимости отдельно повторены
сборка и целевой сценарий обеих тем на 320/390/768/1280. Снимки работающего
приложения просмотрены. Снимки и логи: `artifacts/customer-summary-*`.
