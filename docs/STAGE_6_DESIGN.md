## Визуальное решение

Сохраняем Onest, белую поверхность, фон `#f3f6fa`, синий Qadam `#2455db`, текст
`#122f43`, вторичный текст `#526779`, границы `#dce5ef`. Кнопки и поля соответствуют
действующему приложению. Главная сохраняет карту над формой адресов. Профиль
магазина доступен через общий профиль, основные действия закреплены внизу Mini App.

Смысловой акцент — адрес отправления и время вручения. Личный клиент сразу
видит доставку, без выбора новой роли. После добавления магазина появляется
«Из магазина / С другого адреса». Тип посылки, время и повтор доступны всем.
Цвет, типографику и навигацию для магазина отдельно не меняем.

```text
Общая главная → адреса → получатель, посылка, время → проверка → подтверждение
       ↑
Профиль → Мой магазин → адрес и точка → сохранить

История → Повторить заказ → новый заполненный черновик → проверка → подтверждение
```

## Решения, включённые в предложение

- Один необязательный магазин на аккаунт, отдельной роли бизнеса нет.
- Контакт магазина — собственный подтверждённый номер аккаунта.
- Окно — пожелание для согласования с курьером, без автоматического резервирования.
- При выключенном тарифе — стоимость по согласованию; текущий включённый тариф
  не применяется к будущей дате, создание такого заказа блокируется с объяснением.
- Повтор открывает форму и сбрасывает время/цену/открытку/срочность/подтверждение
  посылки. Новая доставка создаётся только после проверки пользователем.
- Хрупкое и сюрприз видны как инструкции, открытка — назначенному курьеру.
  Готовую открытку передаёт отправитель; услуги печати нет.
- Новые типы не расширяют автоматически условия платного пилота.
