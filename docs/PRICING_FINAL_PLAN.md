# Цена доставки для финальной защиты

Пользователь выбрал автоматическую цену на текущем размещении. Для показа
используется существующий Routing API Geoapify, согласованные ставки и обычное
оформление. Geoapify рассчитывает автомобильную дорогу и время без текущих пробок.
Сумма сохраняется в заказе и истории. На экранах клиента и курьера показано,
что это учебный заказ без оплаты. [Документация Routing API](https://apidocs.geoapify.com/docs/routing/routing/).

Для новых расчётов действует формула `800 ₸ + 70 ₸ × км + 12 ₸ × минуты`,
с округлением вверх до ближайших 50 ₸. Используется расстояние по дорогам.
На проверочных маршрутах Алматы 0,53 км стоили 900 ₸, 4,02 км — 1 150 ₸,
а 14,51 км — 2 050 ₸. Суммы ранее оформленных заказов сохранены.

Расчёт активен для выбранного клиента до 23 декабря 2026 года, 09:42 по времени Алматы.
Заказ появляется только у выбранного автокурьера, а общая рассылка не запускается.
После окончания срока новые расчёты отключаются. Заказы и сохранённые суммы
остаются доступны. На защите можно сказать: «Цена рассчитана по реальному
маршруту, заказ учебный и оплаты нет».

Условия показа — учебное некоммерческое использование в пределах бесплатных
квот. Можно использовать текущее размещение без аренды сервера и покупки Pro.
[Правила Vercel Hobby](https://vercel.com/docs/plans/hobby) ·
[Условия Geoapify](https://www.geoapify.com/terms-and-conditions/).

## Проверка в рабочей версии

1. Код цены опубликован, миграция `20261123040000_geoapify_order_pricing.sql`
   применена в Supabase. Учебный тариф `almaty-car-final-geoapify-v2` активен. Телефоны
   обоих участников подтверждены, заявка автокурьера одобрена.
2. Полностью закрыть и открыть Qadam из Telegram. Создать новый заказ на выбранном
   аккаунте, выбрать два адреса в зоне Алматы и время «Как можно скорее». В
   разделе проверки данных подтвердить условия посылки, дождаться цены.
3. Обновление курьера опубликовано в рабочей версии. Курьер включает смену,
   принимает заказ, отмечает «Посылка у меня» и при вручении вводит код
   получателя. Передача геопозиции для карты доступна в настройках по желанию.
   Миграция `20261123100000_pickup_without_code.sql` уже применена в Supabase.
4. Для досрочного завершения применить [отключение](sql/stage-5-pricing-disable.sql).

Локальный ключ Geoapify подтверждён запросами между публичными точками Алматы.
Ответ TomTom о разрешённом
хранении расстояния/времени и атрибуции нужен для тарифа TomTom. Регистрационное
письмо его не заменяет. Учебный расчёт Geoapify от этого ответа не зависит.

Проверены пересчёт после истечения цены, принятие курьером и сохранение суммы
после повторного открытия заказа. Для новых правил проверены приём без GPS,
забор без кода, вручение по коду и работа карты при добровольной передаче
геопозиции.
