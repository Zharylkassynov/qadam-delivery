# Цена доставки для финальной защиты

Пользователь выбрал автоматическую цену на текущем размещении. Для показа
используется существующий Routing API Geoapify, согласованные ставки и обычное
оформление. Geoapify рассчитывает автомобильную дорогу и время без текущих пробок.
Сумма сохраняется в заказе и истории. На экранах клиента и курьера показано,
что это учебный заказ без оплаты. [Документация Routing API](https://apidocs.geoapify.com/docs/routing/routing/).

Расчёт доступен одному выбранному клиенту семь дней с момента включения.
Заказ появляется только у выбранного автокурьера, а общая рассылка не запускается.
После окончания срока новые расчёты отключаются. Заказы и сохранённые суммы
остаются доступны. На защите можно сказать: «Цена рассчитана по реальному
маршруту, заказ учебный и оплаты нет».

Условия показа — учебное некоммерческое использование в пределах бесплатных
квот. Можно использовать текущее размещение без аренды сервера и покупки Pro.
[Правила Vercel Hobby](https://vercel.com/docs/plans/hobby) ·
[Условия Geoapify](https://www.geoapify.com/terms-and-conditions/).

## Подготовка рабочей версии

1. Курьер открывает Qadam через Telegram, заходит в «Профиль» → «Мой телефон»
   и делится собственным номером. В рабочей базе заявка этого автокурьера
   одобрена и клиентский номер уже подтверждён. На момент проверки номер
   курьера ещё не подтверждён.
2. Применить миграцию `20261123040000_geoapify_order_pricing.sql` через администратора
   Supabase с регистрацией контрольной суммы. Готовый транзакционный файл
   `artifacts/geoapify-demo-migrate.sql` использует существующий журнал миграций.
3. Опубликовать `stage-9-courier-cleanup` через PR в `main`. Перед этой правкой
   содержимое ветки совпадало с опубликованным `main`. В WebStorm выбрать файлы
   приложения и тестов, `package.json`, `package-lock.json`, новую миграцию,
   `docs/ROADMAP.md`, `docs/FINAL_DEFENSE_READINESS.md`, этот план и
   `docs/sql/stage-5-geoapify-demo-enable.sql`. Дождаться зелёной проверки GitHub
   и готовности Vercel. Убедиться, что серверная переменная `GEOAPIFY_API_KEY`
   задана для Production. Используется существующий ключ карт и адресов.
4. Включить режим через [SQL](sql/stage-5-geoapify-demo-enable.sql). На этой машине
   готов `artifacts/geoapify-demo-activate.sql` с двумя согласованными Telegram ID.
   Запускать после публикации, когда оба телефона подтверждены. Результат
   показывает `GEOAPIFY_V1`, `active=true` и время выключения.
5. Пройти один заказ с двух устройств команды. Выбрать точки рядом в Алматы,
   включить смену и GPS у курьера, показать два кода, использовать собственную
   упаковку и сохранить снимок экрана результата для резервной демонстрации.
6. Для досрочного завершения применить [отключение](sql/stage-5-pricing-disable.sql).

До публикации в Telegram действует прежняя версия. Локальный ключ Geoapify
подтверждён запросом между публичными точками Алматы. Получено 4 016 м и около
5 минут в свободном потоке. По действующим ставкам это 1 200 ₸. Ответ TomTom о разрешённом
хранении расстояния/времени и атрибуции нужен для тарифа TomTom. Регистрационное
письмо его не заменяет. Учебный расчёт Geoapify от этого ответа не зависит.
