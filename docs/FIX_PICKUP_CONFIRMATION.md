# Исправление подтверждения забора

11 ноября 2026. Ветка `stage-9-courier-cleanup`.

После принятия заказа кнопка «Подтвердить забор» зависела от `handoff.ready`:
без свежей точной позиции в радиусе 150 м она не открывала даже форму.
Из-за этого нажатие в Telegram выглядело как отсутствие реакции.
На рабочем сервере найден принятый заказ с последней точкой в 183 м от забора;
его статус и данные не изменялись.

## Изменение

- Кнопка сразу открывает существующую форму подтверждения забора или вручения.
- Форма показывает причину недоступности и расстояние до точки, если оно известно.
- «Обновить позицию» непосредственно запрашивает координаты устройства,
  сохраняет их через API и обновляет условия подтверждения. Автоматический
  цикл передачи продолжается. Действие не включает смену и не меняет согласие.
- При отключённой передаче в форме доступны существующие настройки геопозиции.
- Запись забора по-прежнему требует свежей точной позиции у адреса,
  кода отправителя и отметки «Посылка у меня». Серверные правила не менялись.

## Проверка

Браузерный сценарий теперь принимает заказ системной кнопкой Telegram,
открывает форму издалека, проверяет сохранение `ACCEPTED`, обновляет позицию
кнопкой формы, вводит код отправителя и подтверждает забор. Далее проверяются
код получателя, фото, вручение и сохранение результата после перезагрузки.
Этот сценарий воспроизводит ошибку на прежней сборке: кнопка открытия формы
остаётся неактивной. Прогон выполняется на отдельной локальной `_test` базе,
с синтетическими Telegram SDK, координатами и хранилищем фото.

Итог: `typecheck` — успешно; 199 серверных проверок — успешно;
сборка совмещённого приложения, отдельного API и фронтенда — успешно;
`check:build` — 46 + 46 API; 56 браузерных сценариев — успешно
(50 в основном приложении, 5 с отдельным API и 1 защищённая доставка через
отдельный API). Новое открытие формы и обновление позиции проверены в обоих
вариантах приложения. Снимки формы на мобильной ширине просмотрены.
Локальные журналы: `artifacts/pickup-confirm-build.log`,
`artifacts/pickup-confirm-e2e.log`.
